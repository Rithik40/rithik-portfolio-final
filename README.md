# Rithik B — Portfolio

A clean, responsive personal portfolio built with Next.js, React, TypeScript, and custom CSS.

## Run locally

1. Install Node.js 20 or later.
2. Extract this folder and open it in VS Code.
3. In the project folder, run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000.

## Before deploying

- Your LinkedIn profile and the supplied individual GitHub project links have been added.
- Check that the Driver Drowsiness repository URL is the exact repository URL you intended before publishing.
- Add a copy of your resume at `public/Rithik_B_Resume.pdf` if you want to add a resume-download button.
- In `app/layout.tsx`, replace `https://example.com` with your deployed domain before launch.
- Confirm the phone number and email are the contact details you want public.

## Deploy to Vercel

Push the project to a GitHub repository, import it at https://vercel.com/new, and deploy with the default Next.js settings.
